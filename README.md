# 🏁 Pit Wall — GP de Interlagos

Projeto prático desenvolvido durante a disciplina de **Linguagem de Marcação (LIMA)**, com o objetivo de recriar fielmente a interface de uma página temática do Grande Prêmio de São Paulo de Fórmula 1 utilizando exclusivamente **HTML5** e **CSS3**.

---

## 🎯 Objetivos do Desafio

Consolidar os conhecimentos de estruturação semântica e estilização moderna, garantindo fidelidade visual ao layout proposto e adaptação completa para dispositivos móveis e desktops.

### 🛠️ Tecnologias e Conceitos Aplicados
- **HTML5 Semântico:** Estruturação de cabeçalho, seções, tabela de classificação, formulário e rodapé.
- **Variáveis CSS:** Gerenciamento centralizado da paleta de cores das equipes.
- **Flexbox:** Alinhamento do topo (navbar), seção Hero e barra de filtros.
- **CSS Grid:** Layout dinâmico com `auto-fit` para os cards dos pilotos e `form-grid` para o formulário de compra de ingressos.
- **Responsividade:** Adaptação do layout para diferentes tamanhos de tela (mobile e desktop).
- **Estilização Avançada:** Integração com **Google Fonts**, aplicação de imagem de fundo e detalhe visual estilizado remetendo à zebra da pista de Interlagos.
